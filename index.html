A LITTLE CONTEXT

Think in tiny C++ statements.

Most arithmetic instructions read values on the right and write a result to the first register. Memory uses byte addresses; a word here is 4 bytes.

A deliberately small teaching model

32-bit registers, signed decimal display, and no branch delay slots (as in a simulator with delayed branching disabled). These fixed examples avoid overflow. This lab is not a full MIPS assembler.

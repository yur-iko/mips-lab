Instruction traces show how registers, memory, and the program counter change. Guided sessions break calculations and concepts into checkpoints with given values and worked explanations.

A deliberately small teaching model

Traces use 32-bit registers and no branch delay slots. Byte questions use the slides' big-endian convention. Pipeline and cache questions state their assumptions. This lab is not a full MIPS assembler.
